# MP Tourism Board Links — Static Reference Snapshot

This repository contains a static HTML snapshot-style link page plus separate Policy, Maheshwar OBM and water-tourism resource pages.

## Important limitation

The main page contains legacy markup and copied ASP.NET state fields from the source website. It should not be treated as a live mirror of the official MPTB website, and copied page state may become stale or invalid.

## Use and maintenance

- Open `Index.html` in a browser to inspect the static page.
- Use the official Madhya Pradesh Tourism Board website for current policies, notices and authoritative information.
- Before redesigning or deleting legacy markup, inventory every linked document and preserve the useful water-tourism resource pages (`wtapp.html`, `maheshwarobm.html`, and `Policy.html`).
- Treat any copied hidden form state as transient source-page data, not credentials or a reusable API.
